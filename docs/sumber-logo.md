# Sumber logo aplikasi

Ikon diambil dari halaman resmi aplikasi di App Store (Apple) atau Google Play, ukuran 160×160 px format WebP, dan disimpan di `site/assets/logos/`. Nama dan logo adalah merek dagang milik pemiliknya masing-masing; dipakai hanya untuk menunjukkan produk.

Produk tanpa logo resmi yang bisa dipastikan (tampil sebagai monogram): **Loklok** (tidak tersedia di App Store maupun Google Play) dan **Drakor ID** (banyak aplikasi bernama mirip, perlu konfirmasi aplikasi mana yang dimaksud). Untuk menambahkan logonya, simpan file WebP di `site/assets/logos/<slug>.webp` lalu isi field `image` di `site/data/catalog.json`.
